# Privacidad y datos de menores

Marco: Ley N.º 29733 (Perú). El **instituto es el responsable**; este documento resume qué hace el sistema. Revisa la política pública (`privacidad.html`) con tu asesoría legal y completa los datos de contacto.

| Tema | Qué hace el sistema |
|---|---|
| Consentimiento | El portal exige aceptar la política y la autorización de datos; menores de edad: autorización del apoderado. |
| Minimización | Solo nombre, carrera/ciclo, foto y contacto del apoderado (opcional). |
| Fotos | Bucket **privado**; el personal las ve con URL firmada de 1 h. |
| Apellidos en alertas | Parcialmente censurados. |
| Acceso | Por rol y por instituto, con RLS en la base de datos. |
| Derecho de supresión | El estudiante puede **eliminar su cuenta y datos** desde su portal; el administrador puede borrar la foto de un alumno. |
| Retención | Define un plazo (p. ej. 5 años) y elimina datos vencidos. |
| Errores | El registro de errores no guarda datos personales. |
| Historial de cambios | No guarda nombres ni DNI; al eliminar un alumno se purgan sus datos personales del historial. |
| Apoderados | Consulta sin cuenta con un código largo por alumno, solo lectura, con límite de intentos. |

Pendientes del instituto: designar responsable de contacto, definir retención y revisar la política con su asesoría legal.
