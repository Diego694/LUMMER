Base de datos de LUMMER

Elige a qué proyecto de Supabase se conecta LUMMER en este navegador o equipo: la web, el aula, el portal del estudiante y el del apoderado lo usan. Sirve para instalar LUMMER con tu propia base sin tocar el código.

Pega solo la publishable / anon key. Nunca la «service_role» ni una clave secreta: se rechazan. La base nueva necesita el esquema de LUMMER (supabase/schema.sql y migraciones) y una cuenta de superadministrador; las cuentas de la base anterior no se trasladan.
